# 미국 시가총액 TOP 100 대시보드

기존 `dashboard.py`(BigQuery + Dash)를 참고해 만든 3페이지 Dash 앱입니다.
데이터는 실행 시 **Yahoo Finance(yfinance)** 에서 직접 받아오므로 BigQuery 자격증명이 필요 없습니다.

| 경로 | 내용 |
|---|---|
| `/` | 시가총액 상위 100개 순위표 + 선택 종목의 최근 2년 일봉(캔들/라인, MA20·60·120, 거래량) |
| `/top10` | 상위 10개 종목의 1일·1주·1개월·3개월·6개월·YTD·1년·2년 변동률 표, 기간별 수익률 막대, 누적 변동률 비교 |
| `/leader` | 시가총액 1위 기업의 역대 최고 종가 대비 낙폭, 상태(정상/주의/조정/하락장), 가격·누적고점·낙폭 차트, 최근 30영업일 표 |

## 실행

```bash
cd top100
pip install -r requirements.txt
python app.py                  # http://127.0.0.1:8050
DEMO_DATA=1 python app.py      # 인터넷 없이 합성 데이터로 화면 확인
gunicorn app:server            # 배포 (Render, Cloud Run 등)
```

## 동작 방식

- `data.py`의 `UNIVERSE`(미국 상장 대형주 후보 약 170개)의 시가총액을 조회해 **실행 시점 기준 상위 100개**를 선정합니다.
  새로 상위권에 들어올 만한 종목이 있으면 `UNIVERSE`에 티커를 추가하세요.
- 가격은 수정주가(배당·분할 반영) 기준입니다. 1위 기업은 전체 기간 종가로 역대 최고점을 계산합니다.
- 결과는 `cache/`에 저장되고 `REFRESH_HOURS`(기본 6시간)가 지나면 다시 받아옵니다. 첫 로딩은 1~2분 걸릴 수 있습니다.
- 색상은 기존 대시보드와 같이 상승 빨강 / 하락 파랑입니다.
